# Netflix Content Portfolio Analysis and Strategy Insights

## 📌 Project Overview
This project performs a comprehensive content portfolio analysis on Netflix catalog data to understand content strategy shifts over time, country contributions, genre concentration, and rating distributions.

## 🎯 Learning Objectives
1. Explode multi-value columns for proper genre-level analysis.
2. Build percentage-based pivot tables to reveal strategic shifts over time.
3. Analyze content portfolio composition across multiple dimensions simultaneously.

## 📂 Project Structure
- `Netflix_Content_Analysis.ipynb`: Main Jupyter notebook with the complete analytical workflow and visualizations.
- `note.md`: Detailed methodology, content strategy insights, and key findings.
- `netflix_titles.csv`: Raw dataset containing Netflix's content library.
- `*.png`: Exported visualization charts.

## ⚙️ Technical Stack
- **Python 3.13**
- **Libraries**: `pandas`, `matplotlib`, `seaborn`, `numpy`

## 🚀 How to Run
1. Ensure all dependencies are installed (`pip install pandas matplotlib seaborn numpy`).
2. Open the `Netflix_Content_Analysis.ipynb` notebook in Jupyter.
3. Run all cells to view the portfolio breakdown and strategy shift visualizations.
